## 2. 약어 결정 원칙

1. **한 단어 = 한 약어, 한 약어 = 한 단어.** 생성기가 중복이면 기록을 거부한다.
2. **합성어는 '_' 없이**(메모리 std-compound-word-no-underscore) : 업무에서 한 덩어리로 쓰는 말만 합성어로 등재(번호이동 `MNP`, 기본제공 `BSCPRVD`, 가상계좌 `VACCT`, 과오납 `OVPAY`, 자동이체 `ATRF`, 직권해지 `EXOFTRMN`, 이용정지 `SUSP`, 세금계산서 `TXINV`, 상호접속 `INTCN`, 사업자등록번호 `BRNO` 등). 나머지는 표준단어 조합(`_`).
3. **우선순위** : 행안부 공통표준 관행(STTS·TY·SE·KND·APLY·APLCN·BGNG·RSN …) → 국내 이동통신 실무 약어(SBSC·CTRT·BILL·SVC_MGMT·MNP·CLG/CLD) → 이미 다수 영역이 쓰던 표기.
4. **분할 규칙** : 속성명은 등재 단어로 "최소 단어 수" 분할(합성어 우선), 같은 수면 1글자 단어가 적은 쪽, 그래도 같으면 앞 단어가 긴 쪽(사용+량, 사+용량 아님).
5. **용어 = 속성 분류어로 끝남**(`표준단어1_…_분류어`). 도메인은 끝 단어의 대표도메인 + 개념 모델의 길이 변형.

**(2차 정정 — 02 관문 K1 승계)** 엔터티 `phyNm` = 접두어 없는 **`<단어 약어>_<분류어 약어>`**(예 미납기본 `UNPD_BAS`, 사용량월집계 `USE_QTY_MM_AGG`, 지역코드 `RGN_CD`), 테이블명 미리보기 `tblNm` = **`PTL_<주제영역>_<분류어 앞 단어 약어>_<접미어>`**(예 `PTL_COL_UNPD_M`·`PTL_PAY_USE_QTY_MM_T`·`PTL_CUS_RGN_C`). 1차 생성기가 phyNm 자리에 테이블명을 써 넣던 것을 2차 생성기가 두 키로 나눠 계산한다(214개 엔터티 7개 영역 일관, 수작업 금지).
