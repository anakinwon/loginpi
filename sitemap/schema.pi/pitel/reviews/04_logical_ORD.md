## 3. 검토 후 유지한 항목 (지적 아님 — 근거 확인)

- 단말할부상세 회차청구금액·할부잔여원금 : 절사·조정 반영 확정값 / 회차 계획값(회차 행의 사실) — 모델러 근거 타당, 계약 레벨 잔여원금은 L2 로 이미 제거·반정규화 후보 이관.
- 회선상태이력 이전회선상태유형코드 : 다른 행 값(행 내 이행 종속 아님), SCD2 조회 단순화 — 유지.
- 이력 엔터티의 `~변경일시` + `유효시작일시` 공존 : 처리 시점 ≠ 적용 시점(익월 적용 요금제 변경 등) — 다른 사실.
- 결합계약 대표고객번호 ↔ 대표가입계약번호 독립(L8) : 유무선 결합 대표자 ≠ 대표 회선 명의자.
- 회선기본 현재 유심·IMSI·IMEI + 회선변경이력·회선단말관계 : 기본(현재) + 이력(SCD2) 쌍 원칙(docs/01 설계 원칙 1).
