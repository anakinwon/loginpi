## 3. 이월·참고 (P3)

1. PRD-017 로밍국가코드는 저장소 전체에서 유일한 국가 기준 엔터티(PK 국가코드 NATN_CD). CUS.고객기본·PRM.파트너기본의 국가코드는 현재 FK 없는 일반 속성 — 물리 단계에서 같은 키로 참조 정의(FK 설계만, D6) 여부를 결정할 것.
2. ORD 논리 모델의 fk.attr 는 속성명, 초기 PRD 는 물리명이었다가 재생성본에서 속성명으로 통일됨 — 남은 영역(PAY·PRM)도 `fk:{ent, attr(속성명), area}` 형식으로 맞출 것.
3. 물리 모델러 인계 : G1 제거 5칼럼은 조회 경로·건수 근거가 있을 때만 반정규화로 재도입하고 `denorm[]`에 사유 기록.
4. codes.json `요금항목분류유형코드`는 엔터티화(L4)로 폐기 대상 — 표준사전 정리 때 반영.
