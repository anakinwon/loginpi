## 3. 개선 과제(P3 — 통과 영향 없음, 물리·다음 단계 인계)

1. **물리 반정규화 필수 검토(F1 인계)** : 9개 파생 칼럼은 독촉·정지·약정 해제 판정의 주 조회 경로라 물리에서 대부분 되살릴 가능성이 높다. physical `denorm[]` 에 srcTbl·갱신 시점(수납배분·조정·대손)·사유를 적을 것. 미납기본 청구년월(월 파티션 키 후보)도 같은 목록.
2. **미납상세.누적수납금액·미납조정금액** : INV 수납배분상세 합계로도 구할 수 있는 누계값이나, 조정은 별도 상세 엔터티가 없어 원천이 이 속성뿐 — 이번엔 원천 사실로 보고 유지. INV 물리 단계에서 수납배분상세가 미납상세를 가리키게 되면 파생으로 재분류.
3. **다형 참조(V2)** : 미납상태이력.원인업무번호는 원인업무유형코드별 다른 엔터티 PK — FK 미정의. 데이터 생성(S11 고아 진단)·검증 쿼리에서 유형별로 점검.
4. **crossRels 의 영역 내부 항목** : `COL.추심수수료내역 > COL.채권추심사기본`(01 계획 단계 등재)은 영역 내부 관계라 crossRels 대상이 아님 — 물리 단계 전 정리 권고(이번엔 타 단계 산출물이라 무변경).
5. **PRM 논리 미작성** : 추심수수료내역 → PRM.정산기본(정산번호 번호V20)은 PRM 개념 기준 대조. PRM 논리 관문에서 PK 가 바뀌면 COL-020 을 함께 고친다. 채권추심사를 PRM 파트너로 흡수할지(결정 메모 1)도 PRM 관문에서 판정.
