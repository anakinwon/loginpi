8. 적재가 느린 이유와 1µs 차이의 원인

Pi통신 과금
PostgreSQL · Oracle 비교
원인

속도는 함수 실행 방식, 1µs 는 POWER 마지막 1비트에서 갈린다

함수 실행 방식

  • PostgreSQL : SQL 함수를 플래너가 질의에 펼친다. EXPLAIN VERBOSE 에서 gen.uniform(k, 12, 40) 이 hashint8extended(k, 12) 식으로 바뀌어 C 함수가 바로 돈다
  • Oracle : PL/SQL 함수는 펼쳐지지 않는다. 행·칼럼마다 SQL → PL/SQL 전환과 해석 실행을 거친다. 기계어 컴파일(NATIVE)은 컨테이너가 막아 ORA-00600
측정1차 원형2차 튜닝
gen.u 1회8.4µs5.2µs
직권해지 테이블(7,051행)25.1초9.1초
정지 테이블(28,204행)70.5초35.3초

2차 = 해시 32비트 정수(SIMPLE_INTEGER) · 자동 인라인 · 배열 복사 제거. 같은 테이블 PostgreSQL 0.7초 · 2.4초

1µs 차이 : 다른 행의 POWER(x, 0.22) 비트

키PostgreSQLOracle

난수 gen.u 는 두 DB 비트가 같다. 거듭제곱이 1비트 다르면 기간(약 5.3×10¹¹µs)을 곱해 마이크로초로 반올림할 때 1µs 가 갈린다. 같은 값에서 나온 일자(CHAR(8)) 칼럼은 모두 같다.
