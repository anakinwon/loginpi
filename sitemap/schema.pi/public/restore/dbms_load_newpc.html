6. 순위 해석 : 예상과 다른 이유와 보정

예상 Oracle > PostgreSQL > MS-SQL > MySQL · 실제 MS-SQL > Oracle > MySQL > PostgreSQL · 근거 = 실행 로그 조각 시간 합, 테이블 149개 행당 비용 회귀(R² PostgreSQL 0.93) · 기록 = pitel/bench/TEST_RECORD.md 7-1절

결론 : 순위를 가른 것은 엔진 성능보다 DBMS별 생성·저장 조건 차이 2건이다. 두 조건을 보정하면 순위가 마스터 예상과 같아진다(추정)

왜곡 원인근거영향
① PostgreSQL 판만 가중 선택을 PL/pgSQL 함수 gen.wpick 으로 호출(다른 3종 = CASE 인라인)22.99억 회 × 9.75µs = 22,406 작업초PostgreSQL 작업 시간의 36%
② Oracle 판만 14개 칼럼을 CLOB 로(MAX_STRING_SIZE=STANDARD 4,000바이트 한도), 행마다 임시 LOB 생성LOB 테이블 13개(행 8.4%) Oracle 15,621 · MS-SQL 3,783 작업초(4.13배). 나머지 201개는 Oracle 이 4종 중 가장 빠름(MS-SQL 대비 0.73배)Oracle 작업 시간의 35.9%
