## 4. 기능 상세

### 4.1 DB 접속·해제

- 접속 방식 2종 : ORACLE 기반 A/R(Active Repository) 서버, SQLite 파일 (매뉴얼 p148)
- A/R 접속 입력 : A/R 사용자명·비밀번호, 비밀번호 저장 여부, DB 계정(TNS 기반, SYSDBA 선택), SQLite 접속 입력 : 파일 경로 (매뉴얼 p148)
- 접속 제어 메시지 : Wordict 접속 권한 없는 사용자 차단(398), A/R 서버 로그인 실패(346), 읽기 전용 DB 열기(433), 쓰기 가능 위치로 SQLite 파일 이동 안내(438), SQLite DB 유형 오류(432)
- 해제 시 열린 업무 창 전체 닫힘 확인(132), 인증 모듈 `Evaluate50.dll` 부재·손상 시 실행 차단(125·126·127)

### 4.2 표준분류체계 관리

- 목적 : 단어·용어·도메인·코드를 담는 표준 영역(업종·프로젝트 단위) 관리, 리본 콤보 상자에서 선택한 분류체계가 이후 모든 조회·등록의 대상 (매뉴얼 p151, 문자열 367)
- 목록 화면(351) : 표준분류체계 목록 그리드, 새로고침·등록·수정·삭제
- 등록·수정 화면(373) : 표준분류체계명(필수), 설명, 상위 분류체계명, Root로 등록, 사용여부 6종(도메인·용어·어휘구성·표준단어·코드·코드-도메인)
- 규칙 : SQLite 접속 시 계층형 분류체계 미지원(515)

### 4.3 표준 데이터 관리 (조회·출력·수정·삭제)

- 조회 조건(352) : 표준분류, 검색명, 검색 옵션(단어·용어·도메인 선택), 엔터티 분류어·속성 분류어, 도메인 유형, 데이터 타입
- 버튼 : 검색, 계층조회, 등록, 수정, 삭제, 출력
- 하단 상세 : 단어 상세(353 : 논리명·물리명·영문풀네임·한자·분류어·동의어·설명·표준여부·표준단어 여부) + 연관 용어(354), 용어 상세(326 : 논리용어명·물리용어명·논리/물리 구성정보·도메인명·도메인 유형·논리 데이터타입·설명) + 연관 목록(327), 도메인 상세(350) + 연관 목록(325)
- 출력 : 단어집·용어집·도메인 엑셀 출력(문자열 534~536·161~163), 출력 파일은 일괄등록 템플릿으로 재사용 (매뉴얼 p153 Note)
- 수정·삭제 : 단어 수정(336), 용어 수정(338), 도메인 수정(337), 비표준 데이터 수정 불가(402), 연관 용어·코드 존재 시 삭제 경고(158)

### 4.4 동의어 조회

- 조회 조건(320) : 표준분류, 검색명, 관계 유형(동의어·반의어·유의어)
- 결과 : 표준사전 목록 그리드 + 동의어 상세 그리드(323)

### 4.5 표준단어 등록 (단건)

- 입력 항목(362) : 표준분류(선택 분류체계 자동 입력, 변경 불가), 논리명, 물리명, 영문풀네임, 한자, 분류어(엔터티·속성 선택), 금칙 여부, 동의어(콤마 구분), 설명
- 절차 : 중복확인 실행 후 등록 버튼 활성화 (매뉴얼 p155, 문자열 519)
- 규칙 : 사전에 등록된 단어는 동의어로 등록 불가(151), 논리명과 같은 동의어 입력 불가(419), 동일 물리명 단어 존재 시 용어 생성 문제 경고(420), 중복 시 단어 중복 목록 표시(443)

### 4.6 용어 등록 (단건)

- 화면 구성(318) : 표준분류, 검색명, 구분자, 버튼(검색·조회·추가·초기화·적용·용어 후보 조회·용어 정보)
- 생성 방식 : 입력한 용어명을 형태소 분석하여 표준단어 조합 제시, 구성정보·논리용어명·물리용어명은 선택한 단어 조합으로 자동 생성되며 편집 불가, 분석 결과에 미등록 단어 존재 시 단어 등록 버튼 활성화 (매뉴얼 p159~160)
- 도메인 연결 : 용어별 도메인 지정 필수(120)
- 규칙 : 용어는 속성 분류어로 종료(129), 논리용어명·물리용어명 중복 불가(121·382), 유사 용어 존재 경고(404·412), 동음이의어 존재 표시(426·549)
- 관련 구성 요소 : 형태소 분석 모듈 `DAWordAnalyzer.dll`·`EnBaseWordAnalyzer.dll` 설치 폴더 존재(연결 관계 [확인중])

### 4.7 도메인 등록 (단건)

- 입력 항목(331) : 표준분류, 대표 도메인, 도메인명, 도메인 유형(코드·번호·일반), 도메인그룹, 논리 데이터타입, 데이터 길이·소수점, 데이터 범위(최소~최대), 데이터 포맷, 설명
- 도메인명 자동생성 : 대표 도메인 + 논리 데이터타입 + 길이 + 소수점 조합 (매뉴얼 p158, 예시 : 금액DC15 = DECIMAL 15)
- 규칙 : 중복확인 후 등록, 도메인명 중복 불가(115), 사용 가능 안내(369)
