# PRD: schema.pi : 데이터 표준사전 메타시스템

버전 v0.1 · 작성일 2026-10-15 · 상태 설계 확정(구현 착수 전) · 정본 연계 `../../../docs/PRD_28_PI_MULTISITE.md`(상위 플랜), `../../../docs/da/메타시스템_구축_제안서.md`(v0.7), `../../../docs/da/데이터표준규칙.md`, `../../../docs/LOGIN_PLAYBOOK.md`, `../../../docs/MAINNET_READINESS_CHECKLIST.md`(A-5·A-6), `../../../docs/PRD_27_PI_FACTORY.md` · 근거 자료 `requirement/reqst.md`(DA Wordict 메뉴·기능 분석서)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 기관·사업 단위 데이터 표준사전(표준분류체계·단어·도메인·용어)을 팀이 함께 관리하는 웹 메타시스템 |
| 출발점 | 현행 설치형 도구 DA Wordict(ENCORE DA# 5, 5.1.1.8)의 기능을 웹으로 승계(`requirement/reqst.md` FR-01~17) + cafe.pi `/admin/std` 기존 자산 이전 |
| 사용자 | 관리자(분류체계·설정·멤버 관리) · 편집자(표준 등록·신청) · 조회자(조회·출력) |
| 수익 | 체험기간 후 기간 이용권(Pi 결제), 만료 시 조회 전용 전환 |
| 위치 | loginpi 워크스페이스 사이트 앱 `sitemap/schema.pi/` (패키지명 `@site/schema`) |

### 1.1 확정 결정 (2026-10-15 마스터 결정)

| 번호 | 결정 |
|---|---|
| D1 | schema.pi의 성격 = 데이터 표준사전 메타시스템. `sites.json`·`PRD_27`의 EDU(교육정보) 정의는 정정 대상(ROADMAP 0단계) |
| D2 | 팀 공용 웹 시스템(다수 사용자 동시 사용) |
| D3 | 저장소 = Supabase PostgreSQL (개발·스테이징 `pi-nonprod`의 `schema_dev`·`schema_stg`, 운영 별도 프로젝트 : PRD_28 §5 방식 A) |
| D4 | 데이터 모델은 DA# 구조를 복제하지 않고 정규화 재설계, DA# SQLite·Wordict 엑셀은 가져오기 변환기로 연계 |
| D5 | 스택 = sitemap.pi와 동일(Next.js 16 · React 19 · Tailwind v4 · shadcn · next-intl v4 · zod 4 · pnpm) |
| D6 | 인증 = `@pi/auth`(Pi SDK 필수 + Google 연동), LOGIN_PLAYBOOK R6 준수 : Pi 계정 없는 가입 불가 |
| D7 | 결제 = `@pi/payments` 공용 패키지 경유. 패키지 미존재로 sitemap.pi 결제 코드 추출을 선행(0단계), 복제 금지 |
| D8 | 요금 = 체험기간(전 기능) + 기간 이용권(기본 요금 체계), 자동 갱신 구독은 Pi SDK 계약 호출 공식 지원 이후 과제 |
| D9 | 표준 변경 절차 = 기존 `approval_queue` 이전으로 1단계부터 신청→승인 지원, 승인분만 표준 확정 |
| D10 | 용어 물리명 구분자 기본값 `_`, 분류체계별 변경 가능 |

## 2. 범위

### 2.1 포함

| 동의어 조회 | 동의어·반의어·유의어 | FR-06 |

### 4.3 설계 결정

| 번호 | 결정 | 이유 |
|---|---|---|
| M1 | 단어·용어 분리 저장 | 단어(분류어·금칙어)와 용어(도메인 필수)의 속성·규칙 상이 |
| M2 | 현재 값은 본 테이블, 변경 전후 값은 감사 이력 | DA#의 유효기간 PK 행 복제 방식 대비 PK 단순화·조회 조건 제거 |
| M3 | 동시 수정 = 낙관적 잠금(버전 비교, 충돌 시 409) | 팀 공용 덮어쓰기 방지 |
| M4 | 분류체계 내 단어 논리명, 용어 논리명·물리명, 도메인명 유일 제약 | 화면 검사 누락 시에도 DB 보장 |
| M5 | 용어명은 용어 구성 순서대로 단어를 결합해 생성, 직접 편집 불가 | 현행 Wordict 규칙 승계 |
| M6 | 표준 데이터 상태 = 신청중·확정·폐기 | 승인 절차·논리 삭제 공용 |

### 4.4 이전 대상 테이블 확인 사항

- `std_dic`·`std_dom`·`std_term`의 원본 CREATE TABLE 파일 미확인(루트 `sql/004`·`006`·`009`·`010`만 확인) [확인중 : 운영 DB 카탈로그 조회]
- 이전 방식(cafe.pi DB → schema.pi DB 데이터 이관, 이관 후 cafe.pi `/admin/std` 존치 여부)은 1단계 종료 시 결정 [확인중 : 마스터]

| 설정 | `/api/areas/[areaId]/domain-groups` · `abbreviations`, `/api/types` | 목록·등록·수정·삭제 |
| 승인 | `/api/areas/[areaId]/approvals` | 목록·승인·반려 |
| 일괄 | `/api/areas/[areaId]/bulk/{words,domains,terms}` | 검증(dry-run)·반영 |
| 출력 | `/api/areas/[areaId]/export/{words,domains,terms}` | 엑셀 출력 |
| 이력 | `/api/areas/[areaId]/history` | 조회 |
| 결제 | `@pi/payments` 제공 라우트 | prepare·approve·complete·cancel |

- 인증 확인 = 쿠키 OR `X-Pi-Token`(R1), 세션 없음 시 서버 redirect 금지·클라이언트 게이트 위임(R2), UA 기반 Pi Browser 구분 금지(R3)
- 수정 요청은 버전 포함, 충돌 시 409
- 오류 응답 = 오류 코드 + ko·en 메시지
- 입력 검증 = zod 스키마, 공용 가드 `@pi/guard`(본문 한도·요청 빈도)
