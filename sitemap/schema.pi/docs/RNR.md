### 3.3 배포 요청 1회로 끝내는 체크리스트(S6·S8)

1. `git fetch origin` → `git status -sb`, 뒤처졌으면 `git rebase origin/master`(`git pull --rebase` 는 'Cannot rebase onto multiple branches' 재발)
2. `git status --porcelain` 이 비면 '배포할 변경 없음' 한 줄 보고로 끝(빈 커밋 금지 — 환경변수 반영 목적만 예외)
3. dev 중지 확인 → build 통과 → 한국어 커밋 → `git push origin master`
4. 마스터 지시 확인 뒤 `node scripts/promote-to-prod.mjs --app schema --yes`
5. 토큰 인증으로 `commits/<sha>/status` 의 `Vercel – schema: success` 확인 + 환경변수 판정(503/401) → 상태·커밋·시각 한 번에 보고
