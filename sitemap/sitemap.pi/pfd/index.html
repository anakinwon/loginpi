02. 2026-10-11 작업 세션 프로세스

요청 8건 → 커밋 11건(전부 로컬). 빨강은 실제로 막혔던 지점과 해소 방법.

03. 로그인 통합 아키텍처 — 3경로 1세션

Pi Browser = Pi SDK, 일반 브라우저 = Pi Sign-In(OAuth) 또는 Google(NextAuth) + 연동. 서버는 getSessionUser() 하나로 통합.

04. Pi 계정 ↔ Google 연동 시퀀스

Pi Browser 가 6자리 코드 발급(10분) → 일반 브라우저 Google 세션이 입력 → sys_usr_auth_lnk 생성 → 세션 재발급. 2026-10-11 로컬 실왕복 검증.

05. 세션 판정 흐름 — 서버 · 클라이언트

null 이면 서버 redirect 금지(클라이언트 게이트). Google 미연동(user.id='')은 서버에서 null, 클라이언트에서 연동 코드 입력으로 분기.

06. 멀티사이트 플랫폼 로드맵 — Site Kit · 웨이브 게이트

M0~M5 와 PRD_28 §8 웨이브. 각 웨이브는 선행 마일스톤 + 직전 웨이브 회고 없이는 착수 금지.
