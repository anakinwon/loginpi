> 버전 v0.5.3 · 작성일 2026-10-09 · 상태 요구사항 정의(구현 전) · 정본 연계 `../../../docs/PRD_28_PI_MULTISITE.md`(상위 플랜), `../CLAUDE.md`

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | Pi Network에서 만들어진 `.pi` 사이트를 한곳에서 발견·등록·홍보 |
| 사용자 | 방문자(탐색) · 등록자(사이트 운영자) · 관리자(심사) |
| 수익 | 기본 등록 무료, 부가서비스·프리미엄(Pi U2A 결제)으로 **광고 표시된 상단 추천 영역 노출** |
| 차별점 | Pi 로그인·Pi 결제만 사용, 등록 심사·신고 체계로 안전한 디렉터리 |

## 3. 상품 구성

> 요청 "상위 노출 보장" → **구매 기간 동안 상단 추천 영역 노출을 보장**(광고 라벨, 영역 안 순서만 순환, 일반 순위는 결제 비반영). 순위 자체를 파는 방식은 Pi 등재 심사 레드라인이라 순화(근거 : pi-mainnet-listing-auditor 점검 2026-10-09, `../../../docs/MAINNET_READINESS_CHECKLIST.md`). **슬롯 재고 = 동시 노출 수**이므로 구매한 슬롯은 기간 내 항상 화면에 보인다.

가격은 Pi 직접 표기, 단일 출처 `fee_plan`(코드 하드코딩 금지). 단가는 **제안값 [확인중 : 마스터 확정]**.

| 구분 | 코드(fee_knd_cd) | 내용 | 가격·기간 | 수량 제한 |
|---|---|---|---|---|
| 기본형 | REGISTER | 사이트 1건 등록, 카테고리 1개, 소개 500자, 이미지 1장, 일반 순위 노출, 조회수 합계(리뷰 수신은 Phase 3) | **무료** | 심사로 통제 |
| 부가 | CTGR_SLOT | 카테고리 상단 추천 슬롯 | 1 Pi/7일 · 3 Pi/30일 | 카테고리당 3 |
| 부가 | HOME_SLOT | 메인 추천 슬롯 | 2 Pi/7일 · 6 Pi/30일 | 전체 6 |
| 부가 | EXTEND | 같은 슬롯 연장(만료 7일 전부터, 동일 단가, 재고 미차감) | 슬롯과 동일 | 연속 90일 초과 연장 거절, 이후 7일 쿨다운 |
| 부가 | STATS | 일별 조회·클릭·유입 리포트 | 1 Pi/30일 | — |
| 프리미엄 | PREMIUM30 | CTGR_SLOT + HOME_SLOT + STATS 30일 묶음 | 9 Pi/30일(정가 10) | 두 슬롯 재고 모두 확보 시만 |
| 멤버십 | MEMBERSHIP | 계정 단위 프로 멤버십 — STATS 무제한, 등록 5건, 소개 2,000자·이미지 5장, 30일 슬롯·PREMIUM30 10% 할인(하한 1 Pi), 심사 처리 목표 48시간 | 3 Pi/1개월 ~ 영구(§3-1) · 구독(§3-2) | 무제한(비배타) |

- **기간 단위** : 일 단위 고정 — 1개월 = 30일(6개월 180일), 1년 = 365일(2년 730일). 이 문서의 "30일"과 "1개월"은 같은 상품
- **비율 근거** : 재고 한정 상품은 30일 = 7일×3(일할 약 30% 할인, 장기 점유 억제). cafe.pi `sql/089_bean_fee_plan.sql` 스토어 노출(SGGDW 5 → SGGDM 10 Bean)의 ×2는 지면 재고 한정이 아닌 상품 기준이라 승계하지 않음 [확인중 : pricing-promo-manager 재확인]. 최소 1 Pi(0.5 Pi 이하 마이크로 결제 비현실, cafe.pi PRD_24)
- **배지는 판매하지 않음** : "운영자 확인" 배지는 도메인 소유 검증(메타태그/파일) 통과 시 무료
- **구매 자격** : `site_st_cd='APPROVED'`·`del_yn='N'`·`own_site_yn='N'`(자사 사이트 구매 상시 금지)
- **재고·경합** : 유료 주문은 approve 단계에서 재고를 원자적으로 확보한다(실패 시 approve 거절 → Pi 미차감, HELD 15분 경과 시 EXPIRED·재고 반환). 0 Pi 프로모 주문은 주문 생성 시점에 확보한다(실패 시 주문 생성 거절). 재고 0이면 구매 비활성 + 가장 빠른 만료 시각 안내(대기열은 MVP 제외)
- **정지·철회** : 등록자 귀책 SUSPENDED·WITHDRAWN은 슬롯 즉시 회수, 환불 없음(약관 명시). 관리자 오인 후 복구 시 정지 기간만큼 0 Pi 보상 연장

### 3-1. 기간제 요금 (마스터 지시 2026-10-09 : 1개월·6개월·12개월·2년·5년·10년·영구)

7개 기간은 **재고 무제한인 MEMBERSHIP에만** 적용한다. 배타 슬롯(CTGR·HOME·PREMIUM30)은 7일·1개월만 판매 — 장기·영구 판매는 지면 장기 독점·신규 진입 차단을 부르므로 금지. 기간제를 멤버십에 한정한 것은 요청 해석이므로 마스터 확인 대상(§9 #11).

| 기간 | use_days | 1개월 대비 | 가격 | 월 환산 | 할인 | 판매 개시 |
|---|---|---|---|---|---|---|
| 1개월 | 30 | ×1 | 3 Pi | 3.00 | — | Phase 2 |
| 6개월 | 180 | ×5 | 15 Pi | 2.50 | 17% | Phase 2 |
| 12개월 | 365 | ×9 | 27 Pi | 2.25 | 25% | Phase 2 |
| 2년 | 730 | ×16 | 48 Pi | 2.00 | 33% | Phase 2+ (§9 #6~#10 확정 후) |
| 5년 | 1825 | ×36 | 108 Pi | 1.80 | 40% | 동일 |
| 10년 | 3650 | ×60 | 180 Pi | 1.50 | 50% | 동일 |
| 영구 | NULL | ×90 | 270 Pi | 10년 상각 | — | 동일 |

- 기간은 고정 일수(1개월 30일, 1년 365일). 단가는 제안값 [확인중 : 마스터 확정]
- **영구** = 서비스 존속 기간 동안 구매 Pi 계정 1개에 귀속, 양도·현금화·합산 불가, 탈퇴 시 소멸, 핵심 혜택 축소 30일 전 고지. "평생"·"투자" 표현 금지
- **정지** : 멤버십은 계정 귀속이므로 **계정 제재(관리자의 계정 정지)** 시에만 혜택 정지(`ordr_st_cd='SUSPENDED'`) — 기간 계속 차감·환불 없음, 관리자 오인 복구 시 0 Pi 보상 연장. 개별 사이트의 SUSPENDED·WITHDRAWN은 멤버십에 영향 없음
- **수명주기** : 활성 중 추가 구매는 기존 종료일 다음부터 이어붙임, 영구 구매 시 남은 기간 주문은 종료(환불·이월 없음, 구매 화면 고지), 단건과 구독은 동시에 활성일 수 없음 — 단건 이용 중 구독 가입(또는 그 반대)은 기존 종료일 다음부터 이어붙여 시작. 만료 시 한도 초과분(등록 2건째 이후·초과 글자·이미지)은 삭제 없이 비노출 처리, 재가입 시 복원
- **서비스 종료** : 90일 전 고지, 잔여 기간 일할 환불(영구는 10년 상각, 구매 10년 경과 후 환불 없음)
- **멤버십 금지선** : 일반 순위 비반영, 배지 없음, 꾸밈은 상세 페이지 안에서만(목록은 동일 모양), 슬롯 할인은 금액만(재고 상한 동일), 오픈 프로모 대상 제외
- 가격 변경 시 기존 구매자는 주문 시점 금액 스냅샷으로 보호(소급 없음)

### 3-2. 구독 요금 (자동 결제 없음)

Pi는 정기 자동결제 미지원(루트 CLAUDE.md PiRC2 절 "Pi SDK `invokeContract()` 공식 지원 전까지 U2A 결제로 앱 레벨 구독 관리", 2026-10-09 확인) → **기간마다 사용자가 U2A로 직접 결제**해 이어 간다. 구매 화면에 "자동 결제되지 않습니다. 만료 전 직접 결제해야 연장됩니다" 필수 표시. metadata.type `SITE_MBR`(cafe.pi 폐기 `CHAT_SUBSCR` 재사용 금지).

| 항목 | 규칙 |
|---|---|
| 상품 | 월 구독 2.7 Pi(1개월 단건 대비 10%↓), 연 구독 27 Pi(12개월 선불과 같은 가격, 차이는 가격 잠금뿐) |
| 가격 순서(월 환산) | 1개월 단건 3 > 월 구독 2.7 > 6개월 2.5 > 12개월 선불 = 연 구독 2.25 > 2년 이상 — 기간이 길수록 최저가 |
| 구독 혜택 | 갱신 시 최초 가격 유지(가격 잠금) — 갱신 주문 금액 = `prnt_ordr_id` 체인 최초 주문의 `ordr_amt_pi`, 서버는 `fee_plan` 정가가 아닌 이 금액으로 재검증. 알림·유예는 단건 포함 전 멤버십 공통 |
| 알림 | 만료 7·3·1일 전 앱 내 알림(일 1회 배치), Pi 푸시 수단 [확인중 : Pi SDK] |
| 갱신 | 만료 7일 전부터 결제 가능, 새 기간은 기존 종료일 다음부터 |
| 유예 | 만료 후 7일 혜택 유지(전 멤버십 공통). 유예 중 결제 시 기존 종료일 다음부터 이어붙여 유예 일수만큼 차감, 구독은 가격 잠금 유지. 경과 시 종료·재가입은 당시 정가 |
| 해지 | "갱신 안 함" 1버튼, 결제 기간은 만료까지 유지, 환불 없음(법정 청약철회 예외는 §9 #10) |

## 5. 상태 흐름

**사이트 `site_st_cd`**

| 전이 | 주체 |
|---|---|
| DRAFT → PENDING | 등록자 제출(`.pi` 도메인 형식 검증 통과) |
| PENDING → APPROVED / REJECTED(`rjct_rsn_cd`) | 관리자 |
| APPROVED → SUSPENDED → APPROVED | 신고 인용·관리자 직권 / 관리자 복구 |
| 임의 → WITHDRAWN | 등록자 철회 |
| 삭제 | `del_yn='Y'` 논리삭제만(상태와 별개) |

**신고 `site_rpt`** : RECEIVED → ACCEPTED(사이트 SUSPENDED) / DISMISSED
**구매 주문 `fee_ordr.ordr_st_cd`** (슬롯·STATS·멤버십·구독 공통)

| 전이 | 조건 |
|---|---|
| HELD → ACTIVE | 유료 : U2A complete / 0 Pi 프로모 : 주문 생성 즉시(HELD 생략) |
| HELD → EXPIRED | 15분 미결제(재고 반환) |
| ACTIVE → EXPIRED | `use_end_dtm` 경과(멤버십은 유예 7일 경과 후, 영구는 해당 없음) |
| ACTIVE → SUSPENDED → ACTIVE | 계정 제재(멤버십) / 관리자 복구 |
| ACTIVE → REVOKED(`rvk_rsn_cd`) | 사이트 정지·철회로 슬롯 회수 |
| ACTIVE → 갱신 | 새 주문 생성, `prnt_ordr_id`로 연결(연장·구독 갱신 체인) |
| 구독 해지 | `subscr_cncl_yn='Y'` 표시만, 상태는 만료까지 ACTIVE |
| HELD → CANCELED | 사용자 결제 취소 |
| ACTIVE → REVOKED(`rvk_rsn_cd='LFTM_UPGRADE'`) | 영구 구매로 남은 기간 주문 종료 |
| SUSPENDED → EXPIRED | 정지 중 `use_end_dtm`(+유예) 경과 |

**금지 카테고리(REJECTED 사유 코드 고정)** : 도박·베팅·확률형 / Pi 외 통화·법정화폐 결제 / 상품권·현금등가물 거래 / 투자·시세·수익 보장 / 성인 / 개인정보 수집 목적 / `Pi` 접두 도메인·Pi 로고 사용
