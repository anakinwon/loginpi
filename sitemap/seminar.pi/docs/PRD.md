## 2. 핵심 가치 (절대 불가침)

1. Pi Browser 에서 Pi 계정으로 로그인할 수 있어야 한다.
2. Pi Browser 에서 Pi 로 결제할 수 있어야 한다.
3. 개최자가 세미나를 열고, 참가자가 Pi Browser 안에서 실시간 화상 세미나에 들어갈 수 있어야 한다.
