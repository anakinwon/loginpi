## 1. Pi Browser 철칙 — 시험 중 꼭 기억

1. **쿠키가 저장되지 않는다.** 로그인은 앱 안 저장소(토큰)로 유지된다. 주소를 직접 쳐서 다른 도메인(예 `seminarz.vercel.app` ↔ `seminar0532.pinet.com`)으로 옮기면 **로그인이 풀린 것처럼 보일 수 있다** [확인중]. 이때 무한으로 화면이 바뀌면 ✗ — 메모에 적는다.
2. **소리는 손으로 눌러야 난다(자동재생 제약).** 룸에서 소리가 안 나면 "소리 켜기" 를 누른다. 더빙(F-17)은 **스위치를 켜는 탭**이 소리 잠금을 푼다.
3. **iOS 는 더 엄격하다.** 카메라·마이크 권한, 소리 재생, 파일 내려받기가 Android 와 다를 수 있다. iOS 기기가 있으면 **청중 역할**로 같이 들고 한다.
4. **파일 내려받기·새 탭·메일 앱 열기**는 앱 안 브라우저에서 막힐 수 있다 [확인중]. 막혀도 앱이 멈추지 않으면 기능 결함이 아니라 '제약'으로 적는다.
5. 권한 창이 안 뜨면 : 폰 **설정 → 앱 → Pi Browser → 권한** 에서 카메라·마이크를 켠다.

- "이 기기에서는 녹음을 쓸 수 없습니다" → 기기가 녹음 기능(MediaRecorder)을 지원하지 않음. 기기·OS 버전 메모.
- 주소를 쳤더니 로그인이 풀림 → 1절 1번(도메인 이동). Pi 앱 주소(`seminar0532.pinet.com/ko/notes/new`)로도 시험해 메모 [확인중].
- "처리 시간 한도를 다 썼습니다…" / "고지 확인 기록이 없어 멈췄습니다…" → 문구 그대로 메모.

### F-16 번역 자막 (76개 언어)

**선행 조건** : **새 엔진** · **AI 키 반영** · **F-10 방 자막이 켜진 상태** · 보는 사람(B)은 그 세미나에 **참가 등록**(`[입장]`)이 되어 있어야 함 · ADMIN 개최 또는 월간·연간 세미나 · **기기 2대**

**자리** : `⋯` → `자막` → 시트에서 "번역 자막 보기" 스위치 → 켜면 "번역 언어" 선택 칸(위 "내 언어" 묶음, 아래 "모든 언어" 묶음)

| # | 조작 | 기대 결과 | 결과 | 기기 | 메모 |
|---|---|---|---|---|---|
| 16-1 | B : "번역 자막 보기" 켬 | "번역 언어" 선택 칸이 나타난다 | | | |
| 16-2 | B : 선택 칸을 연다 | 맨 위 "내 언어" 몇 개, 아래 "모든 언어" 긴 목록. 언어 이름이 그 언어 글자로 보인다(예 English, 日本語) | | | |
| 16-3 | B : English 선택 → A 가 한국어로 말한다 | B 자막에 **원문이 먼저** 뜨고, 잠시 뒤 **영어 번역문으로 바뀐다** | | | |
| 16-4 | B : 日本語 선택 | 일본어 글자가 깨지지 않는다 | | | |
| 16-5 | B : العربية(아랍어) 선택 | 오른쪽→왼쪽 글이 이름 뒤에서 뒤섞이지 않는다 | | | |

**실패 시 확인**
- 번역문으로 안 바뀜 + "지금은 번역 자막을 쓸 수 없습니다. 원문으로 표시합니다" → 키·외부 AI 오류. 시각 메모.
- "이 세미나의 번역 한도에 도달했습니다. 원문으로 표시합니다" → 세미나 번역 한도 소진(정상 동작). 이 문구가 너무 빨리 나오면 메모(ROADMAP 막힌 것 #9 관련).
- "번역 자막 보기" 스위치 자체가 없음 → 자막 시트가 아님, 또는 화면 버전 확인.

### F-17 음성 번역 듣기 (더빙, 원음 20%)

**선행 조건** : **새 엔진** · **AI 키 반영** · **F-16 번역 언어가 골라진 상태**("원문"이면 스위치가 안 보임) · 방 자막 켜짐 · **기기 2대**(A 말하고 B 듣기) · **B 는 이어폰 권장**

**자리** : 자막 시트 맨 아래 "음성 번역 듣기" 스위치 (켜짐은 저장되지 않음 — 입장할 때마다 다시 켠다)

| # | 조작 | 기대 결과 | 결과 | 기기 | 메모 |
|---|---|---|---|---|---|
| 17-1 | B : 번역 언어 English 상태에서 시트 맨 아래 확인 | "음성 번역 듣기" 스위치가 보인다 | | | |
| 17-2 | B : "음성 번역 듣기" 켬 → A 가 한국어로 한 문장 | B 이어폰에서 **영어 합성 음성**이 나온다. A 원래 목소리는 **작게(약 20%)** 깔린다 | | | |
| 17-3 | A : 쉬지 않고 3~4문장 | 문장이 **순서대로** 나온다(겹치지 않음). 너무 밀리면 오래된 문장은 건너뛴다 | | | |
| 17-4 | B : "음성 번역 듣기" 끔 | 합성 음성이 멈추고 A 목소리가 **원래 크기**로 돌아온다 | | | |
| 17-5 | B : 번역 언어를 한국어로 → 스위치 켬 → A 가 한국어로 말함 | 같은 언어라 더빙 없이 **원음 그대로** 들린다 | | | |
| 17-6 | B : 더빙 켠 채 A 가 "실시간 자막(방 전체)" 끔 | 원음이 원래 크기로 돌아온다(아무것도 안 들리는 상태가 없다) | | | |
| 17-7 | B : 더빙 켠 채 폰 화면을 잠깐 끄거나 다른 앱 → 돌아옴 | 다시 소리가 나는지 [확인중] | | | |
| 17-8 | (C, iOS) 17-2 | iOS 에서도 합성 음성이 나온다 | | | |

**실패 시 확인**
- "번역 음성을 재생하지 못했습니다. 다시 켜 주세요" → 자동재생 제약(1절 2번). 스위치를 끄고 다시 켠다. 그래도 안 되면 기기·OS 메모.
- "지금은 음성 번역을 쓸 수 없어 껐습니다" → 번역이 멈춤(F-16 실패 시 확인과 같음).
- 스위치가 없음 → 번역 언어가 고르지 않았거나 "번역 자막 보기"가 꺼짐, 또는 번역이 멈춘 상태.
- 원음이 계속 작게만 들림 → ✗. 17-4·17-6 결과와 함께 메모.
- 하울링 → 이어폰 없이 한 방에 둔 것. 이어폰으로 다시.
