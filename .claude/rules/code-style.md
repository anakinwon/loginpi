# 코딩 스타일 규칙

> 이 프로젝트의 코드는 산출물(PPT·문서) 생성 도구와 DB 조사 쿼리가 중심이다.
> 언어별 규칙 외에 공통 규칙을 우선 적용한다.

# ---
# 특정 디렉토리만 적용
# paths: src/api/**/*.ts
# ---



## 공통 규칙
- **주석·문서화**: 한국어. **변수명·함수명**: 영어 (코드 표준 준수).
- 파일 상단에 **용도 주석 1~3줄** 필수 (무엇을 만들며/추출하며, 어떻게 실행하는지).
- **하드코딩 금지**: 절대경로·사용자 홈 경로를 코드에 박지 않는다.
  출력 경로 등은 명령행 인자(`process.argv`)로 받고, 기본값은 상대경로로 지정한다.
- 매직 넘버·색상·폰트는 파일 상단 **상수 객체**로 모은다 (예: `const C = { dgray:"595959", … }`).
- 미확정 값은 `[TBD]`/`[확인중]`으로 표기하고 눈에 띄는 색(빨강)으로 처리한다.
- 새 파일을 만들기 전에 기존 유사 파일을 찾아 **수정·재사용을 우선**한다.

## JavaScript (tools/ — PPT 생성 도구)
- 런타임: Node.js, 모듈 방식: **CommonJS**(`require`) — 기존 도구와 통일.
- 파일명: `gen-<장번호>-<용도>.js` 패턴 유지 (예: `gen-4.3.1-비주얼보강.js`).
- PPT 생성은 `pptxgenjs` 사용, A4 가로 레이아웃은 `a4patch.js`를 patch하여 적용.
- 공통 레이아웃 함수(`chrome`, `headline`, `table`, `noteBox` 등)는 기존 도구의
  시그니처를 따라 작성하고, 폰트·색상은 `guide/contents_guide.md`(장표 표준 가이드 통합본) 정의를 따른다.
- 좌표·크기는 인치 단위 숫자 리터럴 허용(레이아웃 특성상), 단 여백·폭 기준값은
  `MX`, `BW` 같은 상수로 계산한다.

## SQL (sql/ — Tibero 7 조사 쿼리)
- 파일명: `<용도>_추출쿼리_for_티베로.sql` 패턴 유지.
- 파일 상단에 **헤더 블록 주석** 필수: 추출항목 / 사용법(DBeaver·tbsql) / 매핑 규칙.
- 키워드는 대문자, 별칭(AS)은 한국어 컬럼명을 큰따옴표로 지정 (예: `AS "테이블명"`).
- SELECT 목록은 컬럼마다 줄바꿈, 콤마는 **줄 앞**에 배치 (기존 스타일 통일).
- Tibero 고유 동작(예: PK POSITION 0부터 시작)은 해당 라인에 주석으로 보정 근거를 남긴다.
- 특정 스키마 필터는 WHERE 절을 주석 처리된 형태로 포함해 두고, 사용법에 안내한다.
- 조회 전용 원칙: 조사 쿼리 파일에는 DML/DDL을 섞지 않는다 (샘플 구축 스크립트는 별도 파일).

## Shell (bash)
- Shebang `#!/usr/bin/env bash` + 파일 용도 주석.
- 줄 끝은 **LF 고정** (Windows 환경이므로 CRLF 오염 주의 — git-rules.md 참조).
- 외부 도구(jq 등)는 존재 여부를 확인하고 **폴백 경로**를 마련한다.
- 외부 입력 값은 빈 값·비정상 값 방어 처리를 기본으로 한다.

## 품질 기준 (완료 조건)
- JS 도구: 작성 후 실제 실행하여 산출물(pptx)이 생성되는지 확인한다.
- SQL: 실행 대상 DB(Tibero)에서 오류 없이 실행됨을 확인하거나, 미확인 시 그 사실을 명시한다.
- 실행 확인 없이 "완료"로 보고하지 않는다.
