## 2. 핵심 쟁점 4건 (결론 승계 금지 항목)

1. **결론 충돌 — 전임자 결론을 그대로 승계하지 말 것.**
   인수 문서 결론(7장)은 "CDC 방식 + DR센터 Read/Write"이나, 현황분석 4.8 확정 판정은
   **Replica형(CDC) 배제, Only App형(TSC 기반 Active-Standby(A-S)) 기준안**(티베로 기술지원팀 권고 일치).
   DR Read/Write는 Active-Active(A-A) 지향으로 Data Conflict 원천 차단 방침과 충돌.
   → 목표모델 결론부는 현황분석 판정 기준으로 재작성. 비교표는 근거 자료로 유지.
2. **"HA" 용어 혼란 — 문서 내부 모순 존재.**
   인수 문서의 "HA"는 **티베로 ADR 패키지의 'HA 방식'(단방향 standby 복제,
   LNW/LNR/SMR)**을 지칭(TAC 센터 내 고가용성과 다름). 비교표(3장)의 "HA=스토리지 블록 복제" 서술은 오류로 보임.
   → 목표모델 장에서는 "ADR-HA(단방향 standby)" 한정 표기 또는 TSC 체계로 통일. HA(TAC)≠DR 원칙 유지.
3. **"ADR(Active Data Replicator)" 실체 미검증.**
   공식 관리자 안내서 체계(TAC/TSC)에 없는 패키지명 — ProSync(CDC)+Tibero HA 묶음 상품으로 추정.
   → 티베로 기술지원팀에 공식 질의 필요: "ADR-HA와 TSC의 관계 + A2 등급 권장 구성" (쟁점 2·3 동시 해소).
4. **등급 전제 과잉 가능성.**
   구성안이 RTO 실시간~1h·RPO Near 0(**A1 스펙**)으로 산정됨. Any-ID가 A2(대국민 필수, RTO 3~12h)로
   확정되면 고시 기준상 Active-Standby로 충분 → 등급 확정 후 목표 스펙 재산정 (과잉 설계 방지).
