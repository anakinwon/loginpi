## 루프 흐름 (링크 순서)

[[마스터]] → [[아소카]] → [[build]] → [[verify]] → [[codex-judge]] → [[teamanakin-admin]] → [[아소카]] → [[마스터]]
되돌림 : [[codex-judge]] FAIL → [[verify]] → [[build]] / escalate → [[decide]] → [[build]] / 팀장 REJECTED → [[build]]

정본 우선순위 : 루트 `CLAUDE.md` → [[anakins_prompt]] 0절 → 각 장표. Codex 세부는 [[codex_procedure]] 가 이긴다.
