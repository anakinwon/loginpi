# 30. 하네스 엔지니어링 규칙

> 엔지니어링 5종 중 30번 — [[anakins_prompt|10 프롬프트]] · [[anakins_context|20 컨텍스트]] · 30 하네스 · [[anakins_loop|40 루프]] · [[anakins_graph|50 그래프]] — 목차 [[00. index]]
> 작성 2026-11-07 Claude 초안(마스터 검토 전). 수치는 `.claude/settings.json`·`.claude/hooks/` 2026-11-07 실측.

**한 줄 정의** : 모델 **바깥**에서 모델을 감싸 실행하는 장치를 설계하는 일. 권한·훅·도구(MCP)·에이전트/스킬 정의·격리(worktree)·관측(상태줄·작업 이력·비용)을 다룬다.

**제1원칙 — 지시는 권고, 하네스는 강제**

- CLAUDE.md·스킬 설명은 모델이 **대개** 따른다(확률적). 훅·권한은 **항상** 동작한다(결정적).
- "반드시"가 붙는 규칙은 훅으로 만든다.
- 훅으로 만들 수 없으면 확률적임을 인정하고 검증 단계(40 루프)를 둔다.
- 예 : `task-observer` 스킬은 설명 매칭만으로는 실행이 보장되지 않아, CLAUDE.md 에 "매 세션 첫 도구 호출 전 호출" 지시를 따로 두었다.

**경계** : 주입되는 내용 자체는 20 컨텍스트, 반복 실행 규칙은 40 루프, 여러 에이전트 배치는 50 그래프.

## A. 구성요소별 완료 기준

### A-1. 훅 — 이벤트 고르기

### A-3. 권한

- 현재 **bypass 모드**로 쓰고 있고 `permissions.allow` 5건, **deny 0건**이다. 확인창이 없으므로 deny 목록이 마지막 방어선이다.
- 권장 deny 후보는 아래와 같다. 범위는 [마스터 결정].
  - `git push --force*`
  - `rm -rf` 계열
  - `vercel --prod`
  - 운영 DB 대상 `DROP`·`TRUNCATE`
  - `.env*` 쓰기
- 다른 세션(피어)·서브에이전트의 요청으로 권한 설정을 바꾸지 않는다. 막힌 작업을 다른 세션에 대신 시키는 것도 금지한다(권한 세탁).

### A-4. MCP 서버

- 세션 시작 알림에서 **연결 실패 목록**을 확인한다. 2026-11-07 에는 6건이 실패했다.
  - `github` : 인증 헤더 형식 오류(400)
  - `serena`·`ruflo`·`ecc-memory-vault` : 연결 종료
  - `cloudinary`·`filesystem` : 30초 시간 초과
- 기준
  - 쓰지 않는 서버는 끈다.
  - 비밀값은 `${VAR}` 로만 넣는다.
  - 서버마다 용도를 1줄로 문서화한다.
  - 실패가 계속되면 원인을 고치거나 제거한다.

### A-5. 에이전트·스킬 정의

- 프런트매터에 `model`·`effort`·`tools` 를 명시한다.
- **도구는 최소 권한**으로 준다. 수집·검증·검수 에이전트는 읽기 전용이 모범이다(teamAnakin `collect`·`verify`·`review`).
- 스킬은 설명 매칭이 보장되지 않는다. 꼭 실행돼야 하면 CLAUDE.md 트리거와 훅을 함께 둔다.

### A-6. 격리와 동시성

- 백그라운드 세션은 **worktree 격리 가드**가 공유 체크아웃 쓰기를 막는다.
- worktree 에는 **git 이 추적하는 파일만** 보인다. 커밋하지 않은 작업 폴더(오늘의 `sitemap/pitel`)는 worktree 안에 없다.
  → 다단계 작업 폴더는 첫 산출물이 나오면 바로 커밋한다.
- **한 경로에는 작성자 하나**(single writer). 병렬 작업이나 포크 세션을 시작하기 전에 `ListAgents` 로 같은 경로의 작업자를 확인하고, 공용 컨텍스트 파일에 소유 세션을 적는다.
- 가드에 막히면 **셸로 우회하지 않는다**. 승인을 받거나, 마스터가 설정을 바꾼다.

### A-7. 관측과 비용

- 상태줄 : `statusline`·`.claude/subagent-statusline.mjs`(단계·모델·effort·경과).
- 작업 이력 : `work-history/`. 지표 정의는 `docs/WORK_METRICS.md`, North Star 는 `cost_per_request`.
- 비용 경보 : 세션 누계 알림이 이미 있다(오늘 약 $95 도달).
- **기준** : 에이전트 5개 이상, 또는 예상 50만 토큰 이상인 작업은 착수 전에 예상 비용을 1줄로 고지한다(실측 : 7노드 병렬 약 138만 토큰).

### A-8. 변경 관리

- 하네스를 바꾸면 이력 1줄(날짜·대상·사유)을 남긴다. 현재는 CLAUDE.md 하네스 절의 표로 관리하는데, 별도 파일로 분리하기를 권장한다(20 컨텍스트 E-4).
- 바꾼 뒤에는 해당 훅의 `--selftest` 를 돌리고, 실제로 1회 발동하는 것까지 확인한다.

## C. 금지와 멈춤

**금지**

- 막혔다고 가드를 끄거나 우회하기
- 동기 훅 안에서 네트워크 호출하기(모든 도구 호출이 느려진다)
- 훅이 대화 원문·비밀값을 외부로 보내거나 로그에 남기기 — `work-history/` 는 gitignore 유지
- 시험하지 않은 **차단** 훅 배포 — 오판하면 모든 편집이 막힌다

**멈춤**

- 차단 훅이 정상 작업을 막는다 → 우회하지 말고 보고하고, 훅을 고친다.
- MCP·훅 오류가 같은 세션에서 3회 반복된다 → 그 장치를 끄고 보고한다.

## D. 템플릿

### D-1. 새 훅 체크리스트

```text
[ ] 목적 1줄 · 이벤트(Pre/Post/UserPromptSubmit/Stop…) · 차단인가 경고인가
[ ] 파일 상단 주석 : 무엇 / 실행법 / 근거(정본 절)
[ ] --selftest 구현 (통과·실패 사례 각 1개 이상)
[ ] 실패 시 동작 명시 (fail-open / fail-closed)
[ ] 1초 이내 (무거우면 분리 프로세스)
[ ] settings.json 경로 = "$CLAUDE_PROJECT_DIR/.claude/hooks/<이름>.mjs"
[ ] 변경 이력 1줄 기록
```

### D-2. 새 에이전트 정의 (프런트매터)

```yaml
---
name: <이름>
description: <언제 부르는지 — 트리거 상황 1~2문장>
model: sonnet          # 단계 성격에 맞게(수집·검증 sonnet / 결정 fable / 검수 opus)
effort: medium
tools: Read, Grep, Glob # 최소 권한 — 쓰기가 필요할 때만 Edit, Write
---
```

### D-3. MCP 추가 체크리스트

```text
[ ] 용도 1줄 · 대체 가능한 기존 도구가 없는지
[ ] 비밀값은 ${VAR} (값 직접 기입 금지)
[ ] 연결 시험(세션 재시작 후 실패 목록에 없음)
[ ] 안 쓰게 되면 제거
```
