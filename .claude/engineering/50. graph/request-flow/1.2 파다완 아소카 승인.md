> 요청 처리 흐름 설계 슬롯 — 생성기 `scripts/request-graph.mjs --design-only --md`(손으로 고치지 말 것) · 그래프 규칙 [[anakins_graph]] · 목차 [[00. index]]

| 항목 | 내용 |
|---|---|
| 역할 | 턴 묶음 판정(Stop 훅 turn-gate.mjs — 보이는 CDX 칸 중 Y 아닌 칸을 Codex 1회로) 뒤 아소카가 직접 종료 승인 — 팀장(teamanakin-admin) 판정은 있으면 근거로 함께 |
| 검수 기준 | 메인 응답 끝 '종료 승인 : <승인|보류> — <근거>' 줄 = 완료(없으면 Stop 훅이 차단, 연속 차단 3회 상한 = 승인 강제 실패) · 팀원이 1명이라도 실행된 턴은 팀장 승인 생략 불가(조회·커밋 단독 턴 제외) |
| 정본 | [[아소카]] · [[teamanakin-admin]] |
| 실행 대응(SLOT_MAP) | 메인 응답의 '종료 승인 :' 줄(세션 기록) — 없음 + Stop 훅 상한 기록 = 승인 강제 실패, teamanakin-admin 실행은 칸 안 줄 |
