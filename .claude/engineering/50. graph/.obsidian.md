# Obsidian 설정 관리

> 이 파일이 **Obsidian 관련 설정의 정본**이다(마스터 지시 2026-11-08). 설정을 바꿀 때는 이 파일에 먼저 적고, 그 다음 앱에 반영한다.
> 앱이 실제로 읽는 설정 폴더 `.claude/engineering/.obsidian/` 는 실행본이며 저장소에 올리지 않는다(`.gitignore` 62행).

## 1. 설치

| 항목 | 값 |
|---|---|
| 버전 | 1.15.0 (2026-11-08 설치) |
| 설치 방법 | `winget install --id Obsidian.Obsidian --exact --scope user --silent` — 사용자 범위, 관리자 권한 불필요, 설치 관리자 해시 확인 통과 |
| 실행 파일 | `%LOCALAPPDATA%\Programs\Obsidian\Obsidian.exe` |
| 갱신 | `winget upgrade --id Obsidian.Obsidian --exact` |
| 제거 | `winget uninstall --id Obsidian.Obsidian --exact` |
| 앱 전역 설정(볼트 목록) | `%APPDATA%\obsidian\obsidian.json` — 첫 실행 후 생긴다(2026-11-08 현재 없음, 아직 한 번도 실행하지 않음) |

## 3. 볼트 설정 (정본 — 앱에 반영할 값)

적용 상태가 `미적용` 인 항목은 볼트를 처음 연 뒤 앱에서 설정하고, 상태를 `적용(날짜)` 으로 바꾼다.

| 구분 | 설정 | 값 | 이유 | 상태 |
|---|---|---|---|---|
| 파일·링크 | 링크 형식 | **위키링크(`[[ ]]`) 사용** — "Use [[Wikilinks]]" 켜기(마스터 결정 2026-11-08) | Obsidian 그래프 뷰가 목적이고, 문서 18개·링크 215개가 이미 위키링크다. 한계 : GitHub·Claude Code 에서는 링크로 렌더되지 않고 문자 그대로 보인다 — 감수 | 미적용 |
| 파일·링크 | 새 링크 경로 | 상대 경로 | 폴더 이름에 공백·번호가 있어 상대 경로가 가장 안전 | 미적용 |
| 파일·링크 | 파일 이동 시 링크 자동 갱신 | 켜기 | 문서 이동 때 링크 깨짐 방지 | 미적용 |
| 파일·링크 | 첨부 파일 위치 | 현재 파일과 같은 폴더 | 그림이 문서 곁에 있어야 저장소에서도 찾기 쉽다 | 미적용 |
| 그래프 뷰 | 색 그룹 | `path:"10. prompt"` · `path:"20. context"` · `path:"30. harnes"` · `path:"40. loop"` · `path:"50. graph"` 다섯 그룹에 서로 다른 색 | 5종 문서 사이의 연결이 한눈에 보이게 | 미적용 |
| 그래프 뷰 | 고아 노드 표시 | 켜기 | 어디에도 연결되지 않은 문서를 찾는 용도 | 미적용 |
| 플러그인 | 커뮤니티 플러그인 | 사용 안 함(제한 모드 유지) | 제3자 코드가 저장소 문서를 읽고 쓰게 되므로 — 쓰려면 마스터 승인 후 이 표에 이름·버전·용도를 먼저 적는다 | 기본값 |
| 플러그인 | 코어 플러그인 | 기본값 유지(그래프 뷰·백링크·검색 등) | — | 기본값 |

설정값이 앱의 `.obsidian/app.json`·`graph.json` 에서 어떤 키로 저장되는지는 [확인중 : 첫 실행 후 실제 파일과 대조]. 키 이름을 추측해 파일을 직접 고치지 않는다 — 앱 화면에서 바꾼다.

## 4. 그래프 엔지니어링과의 관계

- 정본 규칙은 `anakins_graph.md`(같은 폴더). Obsidian 은 그 문서들 사이의 **연결을 보는 도구**이고, 규칙을 바꾸지는 않는다.
- `anakins_graph.md` 의 Mermaid 그림(B-1·B-2)은 Obsidian 미리보기에서도 그려진다 [확인중 : 볼트를 연 뒤 확인].
- 5종 문서끼리 링크를 거는 작업(그래프 뷰에서 흐름이 보이게)은 별도 작업이다 — 범위는 마스터 결정 [TBD : 마스터].

## 5. 주의

- 이 파일 이름이 점(`.`)으로 시작해 Obsidian 파일 탐색기에는 보이지 않을 수 있다 [확인중 : 볼트를 연 뒤 확인]. 보이지 않아도 이 파일이 정본이다.
- `.obsidian/` 폴더(앱 실행본)는 커밋하지 않는다. 기기를 옮기면 이 파일 3절을 보고 다시 설정한다.
- 볼트 안에 비밀값(API 키·접속 문자열)을 적지 않는다 — 저장소 규칙과 같다.
